# Authorized Stream Inspector

一个 Chrome Manifest V3 原型，用于在用户明确有权处理的页面上保存媒体响应数据，或手动录制当前标签页。

## 能做什么

- 通过 Chrome DevTools Protocol 观察当前标签页的网络响应。
- 识别 HLS `m3u8` 清单和 `ts`/`m4s`/`mp4` 分片。
- 读取页面媒体元素的时长、播放状态和 `mediaKeys` 状态。
- 不调用 `captureStream()`，不抓取解码后的画面，也不尝试解密或拼接。
- 在分片第一次传输完成时，通过对应的 `requestId` 读取并缓存浏览器收到的响应体。
- 保存时从内存副本生成文件，不根据 URL 再次向服务器请求。
- 检测到 EME 或 HLS 加密标记时，继续记录请求信息但跳过媒体响应体。
- 界面只显示已获取份数和数据量。
- 点击一次“保存内容”，将本次缓存的全部原始分片写入下载目录。
- 不导出观察清单，界面也不显示 URL 列表。
- 提供独立的“当前标签页录屏”：由用户手动开始、手动停止，并自动保存一个 WebM 文件。
- 标签页录屏采用 OPFS 磁盘流式写入：内部约每 5 秒写入一次，但始终形成一个连续的 WebM 文件，不会生成每秒一个的用户可见分片。
- 录制数据由专用 Worker 直接追加到磁盘，内存不会随录像总大小线性增长；正常录制不设置 512 MiB 总量上限。
- 浏览器崩溃或扩展重载后，会保留最近一份已写入磁盘的未完成录像，并在弹窗中提供“导出未完成录像”。
- 标签页录屏只包含当前标签页的可见页面内容和该标签页声音，不调用桌面录屏，不录其他窗口、桌面或浏览器工具栏。
- 录制在离屏扩展页面中进行，因此关闭插件弹窗不会立刻终止录制；重新打开弹窗仍可停止并保存。

## 加载方式

1. 打开 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本目录：`/Users/marsdrifter/My_Digital_Vault/Nexus/30_Workbench/tencent-stream-inspector`。
5. 打开目标页面，点击扩展图标：
   - 保存原始媒体响应时，点“开始捕获”，播放几秒后点“停止”与“保存内容”。
   - 录制当前标签页时，点“开始录制当前标签页”，需要结束时点“停止并保存”。

## 已知限制

- `chrome.debugger` 权限会让 Chrome 显示调试连接提示。
- 标签页录屏要求 Chrome 116 或更高版本，并使用 `tabCapture` 与 `offscreen` 权限。
- 标签页录屏不是 DRM 绕过工具；站点可能让受保护画面黑屏、静音或直接拒绝播放。
- OPFS 不可用、磁盘写入失败或写入队列持续积压时，插件会拒绝开始或保护性停止，并保留已经写入的内容。
- 中断恢复的 WebM 按已写入字节原样导出；极端中断时可能可以播放但拖动定位信息不完整。
- 需要为本地扩展保留足够磁盘空间。`unlimitedStorage` 只避免扩展配额限制，不能绕过系统磁盘容量。
- 这是原始流观察与保存探针，不是 DRM 解密器。保存操作不会重新请求媒体 URL。
- 单个分片缓存上限为 32 MiB；一次会话最多缓存 20 片、合计 128 MiB，超出部分只记录 URL。
- Chrome 可能不为某些流式、缓存或已回收的请求提供响应体；此时插件明确记录失败，不回退到 URL 下载。
- 保存下来的媒体文件可能仍是加密数据、TS 封装或不可独立播放的分片；当前版本不负责拼接、解密、转码或重封装。
